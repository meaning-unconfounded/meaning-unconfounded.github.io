EROS LIBRARY - TWO PARALLEL SITES (updated 2026-11-23)

SITES
  Extended Edition (the full book)   https://meaning-unconfounded.github.io/   31 pages: <Page>.html
  V2 Ghost Edition (short, cinematic) https://eros-062cf.pages.dev/            31 pages: <Page>_v2.html
Both are built from the same GitHub repository, so every file exists on both domains. Each page names its own home in its canonical, og:url, og:image and share links; every V2 page carries three switch links to its extended twin, and every extended page three links to its V2 twin.
index.html and SpaceEros.html are deployed separately and are not in these zips.

DEPLOY ORDER
  1. V2 pages (EROS_V2_final)  2. Extended pages (EROS_extended_fixed)  3. site files (robots.txt, sitemap.xml, sitemap_v2.xml)
  After deploy, paste a link into X / Telegram / WhatsApp / Facebook; re-scrape if an old preview shows.

SITE FILES
  robots.txt       allows all crawlers and lists both sitemaps.
  sitemap.xml      index + 31 extended pages + SpaceEros (github.io addresses).
  sitemap_v2.xml   31 V2 pages (pages.dev addresses).
  media-manifest.json  machine-readable catalogue of films, audio and plates (github.io addresses).

SHARE CARDS
  images/share/<Page>.jpg for the extended pages, images/share/<Page>_v2.jpg for V2.

IF A DOMAIN CHANGES
  Change the domain in canonical, og:*, share links, the switch links, both sitemaps, robots.txt and media-manifest.json.

NOTE
  Working notes (CHANGES.txt, REVIEW_NOTES.txt, EROS_SOCIAL_SHARING_UPDATE.txt, REPAIR_NOTES.txt) are public if they sit in the published root.
